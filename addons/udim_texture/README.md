# UDIM Textures для Godot 4.7 (v1.2.1)

Материал и набор тайлов для мешей с UDIM-развёрткой. Работает без правок движка:
номер тайла выбирается по целой части UV, у каждого тайла свой сэмплер в
сгенерированном шейдере.

Текстуры подключаются двумя способами: **перетащить PNG-файлы прямо в инспектор**
(быстро) или указать папку и нажать кнопку (для больших наборов).

Это полноценный PBR-материал по схеме **metallic/roughness**: альбедо, металность,
шероховатость, нормали, эмиссия, AO и Height-параллакс — каждая карта своим
набором тайлов.

Протестировано на **Godot 4.7.2** (Forward+, Vulkan).

## Установка

1. Скопируй папку `addons/udim_texture` в `<свой проект>/addons/`
   (архив уже содержит `addons/udim_texture/…` — можно распаковать в корень проекта).
2. `Project → Project Settings → Plugins` → включить **UDIM Textures**.
3. Перезапуск редактора не нужен.

Плагин регистрирует два класса:

| Класс | Что это |
|---|---|
| `UDIMTextureSet` | тайлы одной карты (BaseColor, Normal, ...) |
| `UDIMMaterial` | материал, который собирает тайлы в шейдер |

## Какие карты понимает

| Слот | Карта | Как используется |
|---|---|---|
| albedo | BaseColor / Albedo / Diffuse (sRGB) | `ALBEDO` |
| metallic | Metallic / Metalness | `METALLIC` |
| roughness | Roughness | `ROUGHNESS` |
| normal | Normal Map, OpenGL-стиль (Y+) | `NORMAL_MAP` + Normal Strength |
| emission | Emissive / Emission | `EMISSION` (× Emission Color × Energy) |
| ao | Ambient Occlusion | `AO` (× AO Strength) |
| height | Height / Displacement / Bump | параллакс UV (рельеф «на глаз») |

Всё, что не задано картой, берётся из параметров (Metallic, Roughness, Albedo Color
и т.д.), поэтому можно использовать только часть карт — например, только BaseColor.

## Быстрый старт: перетащить PNG (рекомендуется)

1. Создай материал как **отдельный файл**: в доке FileSystem `ПКМ → Create New →
   Resource… → UDIMMaterial`, сохрани как `res://udim_character.tres`
   (не создавай материал внутри инстанса FBX — там инспектор только для чтения).
2. Текстуры должны лежать в проекте (`res://textures/…`) и быть импортированы.
3. Выдели в FileSystem нужные PNG (можно все сразу, Ctrl+клик / рамкой) и перетащи
   их на поле **PNG Textures** в инспекторе материала.
4. Всё. Карты разложатся по слотам автоматически: слово в имени файла задаёт карту
   (`BaseColor`, `Normal`, `Height`…), четыре цифры — номер тайла (`1001`, `1002`…).
   В **Output** будет список: `albedo: тайлы 1001, 1002` и т.д.
5. `Ctrl+S` — сохранить материал.
6. Назначь материал мешу: `MeshInstance3D → Material Override`.

Поле **PNG Textures** — это только «вход» для drag&drop, в `.tres` оно не пишется:
сохраняются уже разложенные тайлы в слотах. Поэтому после перезапуска редактора
список пустой, а материал работает.

Слоты `*_tiles` (Albedo Tiles, Normal Tiles…) принимают ресурс `UDIMTextureSet`,
а не PNG — это ручной/продвинутый вариант (см. ниже). Кидать картинки нужно в
**PNG Textures**.

## Подключение своих текстур — по шагам (импорт из папки)

### 1. Подготовь файлы

Одна карта = один файл на тайл. Имя заканчивается номером UDIM из 4 цифр:

```
MyChar_BaseColor.1001.png     MyChar_BaseColor.1002.png
MyChar_Metallic.1001.png      MyChar_Metallic.1002.png
MyChar_Roughness.1001.png     MyChar_Roughness.1002.png
MyChar_Normal.1001.png        MyChar_Normal.1002.png
MyChar_Height.1001.png        MyChar_Height.1002.png
```

Требования:

- шаблон имени — `Имя.1001.png` (4 цифры перед расширением). Префикс `Имя` — любое,
  но одинаковое для всех карт персонажа;
- номер UDIM: `1001 + U + 10*V`, диапазон `1001..1999`. Тайл 1001 — UV `U 0..1`,
  1002 — `U 1..2`, 1011 — `V 1..2` и т.д.;
- в имени файла должно быть ключевое слово карты (см. таблицу ниже);
- размеры тайлов могут быть разными, сетка не обязана быть плотной (1001 и 1004 без
  1002/1003 — нормально);
- если в папке несколько персонажей — разложи по разным папкам или задай префикс.

### 2. Положи текстуры в проект

Например `res://textures/MyChar/`. Дождись импорта (полоса прогресса внизу).

Рекомендации по импорту в Godot:

- **Normal** → выдели файлы → в доке **Import** → `Compress → Normal Map = Enable`
  (или оставь `Detect`). Если карта из DirectX-пайплайна и нормали выглядят
  «вдавленными», включи `Process → Normal Map Invert Y`;
- `Detect 3D` оставь включённым — Godot сам включит мипмапы и VRAM-сжатие;
- отдельная настройка sRGB для Roughness/Metallic/Height не нужна: в Godot 4
  преобразование задаётся hint'ом сэмплера в шейдере, и эти карты читаются как
  линейные данные (`source_color` стоит только у albedo и emission).

### 3. Создай материал

Любой из способов:

- в файл-системе: `ПКМ → Create New → Resource… → UDIMMaterial`;
- на меше: `MeshInstance3D → Geometry → Material Override → New UDIMMaterial`.

### 4. Заполни импорт в инспекторе

| Поле | Что вписать |
|---|---|
| **Import Folder** | путь к папке с тайлами, например `res://textures/MyChar` (поле текстовое — путь можно просто напечатать; кнопка **«Выбрать папку»** открывает диалог) |
| **Import Prefix** | общая часть имени до карты: `MyChar_` (пусто — брать все файлы папки) |

Затем нажми кнопку **«Собрать материал из папки»** (если папку выбирал кнопкой,
сборка запускается сразу).

Карты раскладываются по слотам по ключевым словам в имени файла:

| Слот | Слова в имени файла |
|---|---|
| albedo | `basecolor`, `base_color`, `albedo`, `diffuse`, `color`, `colour` |
| roughness | `roughness`, `rough` |
| metallic | `metallic`, `metalness`, `metal` |
| normal | `normal`, `nrm` |
| emission | `emissive`, `emission`, `emit` |
| ao | `ao`, `occlusion` |
| height | `height`, `heightmap`, `displacement`, `disp`, `parallax`, `bump` |

Файлы с другими именами пропускаются — об этом пишется в консоль.

### 5. Проверь консоль

В панели **Output** должно появиться примерно такое:

```
UDIMMaterial: привязано карт: 5
  MyChar_BaseColor -> albedo
  MyChar_Height -> height
  MyChar_Metallic -> metallic
  MyChar_Normal -> normal
  MyChar_Roughness -> roughness
```

Если карта попала в строку «пропущены (нет подходящего слота)» — в её имени нет
ключевого слова; переименуй файлы или назначь набор вручную (см. ниже).

### 6. Сохрани материал

Кнопка собирает материал **в памяти**. Нажми `Ctrl+S` (или `Save` в инспекторе),
чтобы материал сохранился в `.tres` рядом с ресурсом, который ты создал на шаге 3.

### 7. Назначь материал мешу

- `MeshInstance3D` → **Material Override** (перекрывает все поверхности) или
  **Surface Material Override** для конкретной поверхности;
- для импортированной модели (FBX/glTF) открой свою сцену, перетащи туда модель и
  включи у инстанса **Editable Children** (ПКМ по узлу) — тогда правки
  `MeshInstance3D` сохранятся в твоей сцене, а не в импортированном файле.

### 8. Настрой под свой ассет

Подробности по параметрам — ниже. Минимально: **Normal Strength**, **Height Scale**
и **Height Base**.

## Подключение вручную (через UDIMTextureSet)

Нужно, когда имена файлов нестандартные, карты лежат в разных папках или один
тайл надо заменить вручную. Для обычных случаев проще перетащить PNG в
**PNG Textures**.

1. `Create New → Resource… → UDIMTextureSet`.
2. Указать **Folder** и **Base Name** (`MyChar_BaseColor`), нажать **Сканировать папку**
   — словарь `Tiles` заполнится сам (можно вписать тайлы руками: ключ — номер UDIM).
3. В `UDIMMaterial` перетащить набор в нужный слот (Albedo Tiles, Normal Tiles,
   Height Tiles, ...).

Так удобно, когда имена файлов нестандартные или карты лежат в разных папках.

## Параметры материала

| Параметр | Описание |
|---|---|
| Albedo Color | множитель к текстуре альбедо |
| Metallic / Roughness | используются, только если нет соответствующих карт |
| Specular | сила блика |
| Normal Strength / Normal Flip Y | глубина нормалей и переворот зелёного канала |
| Emission Color / Energy | эмиссия (умножается на Emission-карту) |
| AO Strength | сила затенения от AO-карты |
| Height Scale | сила параллакса: смещение UV на единицу высоты (0 — выключить) |
| Height Steps | итераций уточнения (1 — простой параллакс, 8 — точнее на скользящих углах) |
| Height Base | значение Height-карты, соответствующее плоскости меша (`0.5` — типовая запись, `0` — если чёрный = база) |
| Height Flip | инвертировать Height-карту |
| Alpha Scissor | 0 — выключено; иначе альфа ниже порога отбрасывается (`discard`) |
| Use Vertex Color | умножить альбедо на цвет вершин |

## Height (параллакс)

Height-карта не меняет геометрию — UV смещаются в шейдере, поэтому рельеф
«объёмный» только на глаз (силуэт остаётся плоским). Порядок настройки:

1. Height-карта попадает в слот `height` автоматически (имя файла содержит
   `Height`/`Displacement`/`Bump`) или вручную — **Height Tiles**.
2. **Height Base** — уровень плоскости меша. Для карт, испечённых с серой базой
   (Blender/Substance, средняя яркость ~0.5), оставь `0.5`; если чёрный = база, поставь `0`.
3. **Height Scale** — начни с `0.02`–`0.05` и поднимай до появления рельефа.
   Слишком большое значение даёт «плывущую» текстуру на скользящих углах.
4. **Height Flip** — если выпуклости выглядят впадинами.
5. **Height Steps** — 4–8 обычно достаточно; 1 = самый быстрый вариант.

Смещение всегда ограничено текущим тайлом, поэтому соседние тайлы не «протекают»
друг в друга.

## Если что-то не работает

| Симптом | Причина | Решение |
|---|---|---|
| поля и кнопки в инспекторе серые, ничего не вписывается и не нажимается | материал открыт **внутри инстанса FBX/glTF** — такой инспектор только для чтения | создай материал отдельным `.tres` (`Create New → Resource… → UDIMMaterial`) или включи у инстанса **Editable Children** |
| PNG не перетаскивается в `Albedo Tiles` / `Normal Tiles` | слоты принимают `UDIMTextureSet`, а не картинки | перетаскивай PNG в поле **PNG Textures** |
| после перезапуска поле **PNG Textures** пустое | список — только помощник drag&drop, в `.tres` не сохраняется | это нормально: тайлы уже лежат в слотах и материал работает |
| `пропущены (нет подходящего слота)` в консоли | в имени нет ключевого слова карты | переименуй файл (`…_Roughness.1001.png`) или назначь `UDIMTextureSet` вручную |
| `привязано карт: 0`, файлы не найдены | имена не по шаблону `Имя.1001.png` | проверь 4 цифры UDIM и расширение; префикс должен совпадать |
| видна только часть модели (один тайл) | UV модели лежат в 0..1 у всех тайлов, либо тайлов не хватает | разверни модель в UDIM (Blender: UV → UDIM) или добавь файлы тайлов |
| текстура «съехала» на соседнюю деталь | номер тайла в файле не совпадает с UV | 1001 = U 0..1, 1002 = U 1..2, 1011 = V 1..2 |
| нормали выглядят вдавленными | DirectX-стиль карты | `Normal Flip Y` в материале или `Process → Normal Map Invert Y` в импорте |
| Height не виден | `Height Scale` = 0 или неверный `Height Base` | поставь 0.03 и `Height Base` = 0.5 (или 0 для чёрной базы) |
| тонкая полоса/шов на стыке тайлов | линейная фильтрация на самом краю текстуры | запекай карты с отступом (padding/dilate) за границу UV |
| материал «обнулился» после перезапуска | материал не сохранён | после сборки нажми `Ctrl+S` |
| карта в слоте, но эффекта нет | карта не того типа (sRGB normal, пустой тайл) | проверь импорт карты и содержимое `Tiles` |

## Как это работает

- UV модели должны быть **в UDIM-пространстве**: тайл 1001 → `U 0..1`, 1002 → `U 1..2`,
  1011 → `V 1..2` и т.д. То есть UV выходят за пределы 0..1 (нормальное поведение
  развёртки UDIM из Blender/Maya/Substance).
- Шейдер считает `cell = floor(UV)` и берёт тайл с этим номером, а семплирует
  по `UV - cell`. Поэтому тайлы могут быть разного размера и не обязаны лежать рядом.
- Шейдер генерируется под конкретный набор тайлов (по одному `sampler2D` на тайл),
  поэтому материал корректно сохраняется в `.tres` и загружается без пересборки.
  `Texture2DArray` намеренно не используется: Godot не сериализует массивы текстур
  в ресурс (в файл попадают пустые изображения).

## Ограничения

- Height — параллакс (смещение UV), а не реальное смещение геометрии: силуэт не
  меняется, на очень скользящих углах возможны искажения (ограничение
  `view_ts.z` в шейдере и `Height Steps` сглаживают их).
- Прозрачность — только `Alpha Scissor` (жёсткий порог), режим blend-прозрачности
  не включён.
- Упакованные карты (ORM: roughness/metallic/AO в каналах одного файла) не
  поддерживаются — нужен отдельный файл на карту.
- Каждый тайл — отдельный сэмплер: при 30+ тайлах в одной карте шейдер становится
  тяжёлым и может упереться в лимит текстурных слотов GPU (в консоль выводится
  предупреждение после 32 тайлов).
- Имя файла разбирается как `name.####.ext` — файлы вроде `name.1024.png`
  (разрешение в имени) будут приняты за тайл UDIM.
