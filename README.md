# UDIM для Godot 4.7 — аддон UDIM Textures v1.2.1

Готовый аддон: `addons/udim_texture` — скопировать в проект и включить в
`Project Settings → Plugins`. Подробности: `addons/udim_texture/README.md`.
Готовый архив: `finals/udim_texture-v1.2.1.zip` — распаковать в корень проекта
(внутри уже `addons/udim_texture/…` и README с инструкцией). В git архивы не
хранятся — они выкладываются в **Releases**; как это сделать, пошагово в `PUBLISH.md`.


## Что умеет

| Возможность | Детали |
|---|---|
| PBR | metal/rough: albedo, metallic, roughness, normal, emission, AO, **Height (параллакс)** |
| Тайлы | любые номера UDIM 1001..1999, сетка не обязана быть плотной |
| Импорт | перетащить PNG в инспектор (самое быстрое) или папка + префикс, имена `name.1001.png` |
| Сохранение | материал сохраняется в `.tres` и грузится без пересборки |

## Подключить свои текстуры (кратко)

1. Разложи файлы как `Имя_BaseColor.1001.png`, `Имя_Roughness.1001.png`,
   `Имя_Normal.1001.png`, `Имя_Height.1001.png` и т.д. (4 цифры UDIM перед
   расширением) и положи в проект, например `res://textures/MyChar/`.
2. Для карт Normal включи в доке **Import** → `Compress → Normal Map`.
3. Создай **отдельный** `UDIMMaterial` (`Create New → Resource…`), выдели PNG в
   FileSystem и перетащи их на поле **PNG Textures** — карты и тайлы разложатся
   сами. (Альтернатива: **Import Folder** = путь к папке, **Import Prefix** =
   `MyChar_`, кнопка **«Собрать материал из папки»**.) Затем `Ctrl+S`.
4. Назначь материал в **Material Override** нужного `MeshInstance3D`
   (материал внутри инстанса FBX не редактируется без **Editable Children**).

Полная инструкция с таблицей ключевых слов, параметрами Height и разбором
проблем — `addons/udim_texture/README.md` (он же лежит в архиве).


## Что не так было со старым плагином

| Проблема в 0.2 (Godot 4.2) | Как сделано сейчас |
|---|---|
| Хардкод 30 слотов `tile_1001..tile_1030` | тайлы берутся из набора/папки, любые номера UDIM |
| Сеттер `@export` генерировал шейдер и вызывал `set_shader_parameter` до присвоения шейдера | генерация и параметры разделены, шейдер создаётся в `_init` и при изменении набора |
| 30 сэмплеров в шейдере всегда | только реально назначенные тайлы |
| Выбор тайла по 4 порогам из константы (ломается на нестандартных сетках) | `cell = floor(UV)`, тайл по номеру UDIM |
| Импорт через `EditorFileDialog` + `push_error` без обратной связи | папка + префикс в инспекторе, кнопка, отчёт в консоли |
| Неверные `set_shader` (в старой версии — пустой вызов), мусорные параметры | — |

## Ограничения

- Height — параллакс (смещение UV), а не реальная геометрия: силуэт не меняется.
- Прозрачность только через `Alpha Scissor` (`discard`).
- Один сэмплер на тайл: при десятках тайлов шейдер тяжелеет (предупреждение после 32).
